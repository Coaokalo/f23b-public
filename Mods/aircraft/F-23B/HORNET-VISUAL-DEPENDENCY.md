# Installed Hornet burner dependency

This private candidate references the owner's installed DCS Hornet resources:

- `F18C_afterburn`: five-stage burner artwork on original F-23B source surfaces.
- `afterburner_f-18c` and its native circle texture: exhaust and shock effects.

Eagle Dynamics retains ownership of these resources. No Hornet texture files or
engine/nozzle geometry are included in the runtime package. The Hornet texture
archive is mounted by its own CoreMods entry and remains an installation
dependency. Texture colors are unchanged. Source geometry is project-authored;
engine hardware is the retained purchased YF-23 geometry.

Power arguments 29/28 select burner stages; 325/324 animate restrained source
motion. Plume dimensions are fitted to the F-23B's recessed exhaust channels.
This private experiment does not establish public redistribution clearance.
