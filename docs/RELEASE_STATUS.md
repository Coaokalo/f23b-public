# Release staging

The repository and experimental preview release are staged privately. The aircraft
download, corresponding source archive, checksums, player documentation, and launch
announcement are prepared for publication.

The preview's scope and limitations are described in
[the release notes](RELEASE_NOTES.md) and [known limitations](../KNOWN_ISSUES.md).
The [launch announcement](LAUNCH_ANNOUNCEMENT.md) is prepared copy; it has not been posted.

Publication is the remaining launch step: make the repository public and publish
the prepared preview release when the owner chooses to launch.
